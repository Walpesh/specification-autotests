1. Общие сведения и требования
Документ содержит полный набор тест-кейсов для тестирования формы регистрации в соответствии с предоставленными требованиями (функциональными, валидационными и UI/UX).

Ключевые спецификации:
• Логин: 5-20 символов, латиница, кириллица, спецсимволы _, -, @.
• Пароль: 6-33 символа, латиница, кириллица, цифры, спецсимволы.
• Повторите пароль: идентичность полю Пароль.
• Пол: select с 2 значениями (Мужской, Женский).
• Почта: валидация формата, домены @mail, @gmail, @yandex.ru.
• День: 1-2 цифры (1..31).
• Месяц: select с 12 месяцами.
• Год: ровно 4 цифры, макс. возраст 90 лет.
• UI: активный border темно-синий #305BAB, лейбл уходит вверх, кнопка Регистрация зеленая #2DC75C при заполнении всех обязательных полей (*), серая #B0B0B0 при незаполненных. Адаптивность mobile, tablet, desktop.
